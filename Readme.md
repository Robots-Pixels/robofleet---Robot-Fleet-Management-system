# ROBOFLEET, THE PROJECT.

## What is the project?
- Name : ROBOFLEET
- Description : A responsive web app to keep track and control the state of virtual robots inside a simulation. 
  
## What is the MVP (Minimal Viable Product)?
- Responsive web app
- Multi-Users ( Admin who creates the robots, and Operators who assigns missions and keep track of the robots states ... )
- Register robots, give it an identity and an initial state
- Track and manage robots state ( IDLE, ACTIVE, ERROR )
- Assign missions to the robots
- Track missions states ( PENDING, RUNNING, COMPLETED ... )
- Mission Logging ( Record every significant event and is the timeline of actions and states. )
